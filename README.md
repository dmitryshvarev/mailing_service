## Mail Sending


---

> Запуск Django проекта командой **python manage.py runserver**

> Остановить сервер - **CTRL+C**
---

## Технологии:
- Python
- Bootstrap
- Django
- PostgreSQL
- Redis

---

## Описание:

> Чтобы удержать текущих клиентов, часто используют вспомогательные, или «прогревающие», рассылки для информирования и привлечения клиентов.
Mail Sending - сервис управления рассылками, администрирования и получения статистики.
